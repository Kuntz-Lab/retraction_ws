# retraction_ws

Set up with `./post-clone.sh`, which imports the repos in `pushvibes_experiments_dvrk.repos` into `src/` and builds them.

> **Note:** `retraction_pkg` depends on `dvrk_python` and `crtk_python_client` from `~/dvrk_ws`. Source `~/dvrk_ws/install/setup.bash` before you build and run your workspace. You can also build your package inside `dvrk_ws`.
